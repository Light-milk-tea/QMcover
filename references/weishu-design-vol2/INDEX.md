## 案例 A：墨绿 HUD（`final-a.jpg`）

- 黑绿底，满版暗网格、刻度圆环（0～330 的度数刻字）、准星和几道墨绿粗圆弧。
- 左侧方形立绘卡片：白边，略微倾斜，下方贴 `RHODES ISLAND` 小标签和一行点阵。卡片下面是倾斜的英文名 `MAGALLAN` 和 `NOT FOR NEW MODE`。
- 右侧三行标题：上下两行是薄荷绿小字，中间是白色大字，套方括号「」，字面有横向扫描线。
- 右上 `WHY FOR THIS` 绿色小标签；角落是 `FILE`、编号这类终端小字。
- 制作帧里能看到：先做白底标题和扫描线纹理（a_013–a_016、a_034–a_035），再加暗底、圆环、卡片和小字。

## 案例 B：白红 HUD（`cover.jpg`、`final-b.jpg`）

- 白底浅灰的大刻度圆环、准星、灰色粗圆弧，四周散着度数刻字。
- 背后一层超大红色英文名 `SURTR`（被切开、错位，带网点），压在立绘后面。
- 左侧立绘卡片：白色证件卡，红色描边，顶部 `RHODES ISLAND / OPERATOR SELECTING`，底部 `SURTR ARKNIGHTS RECORD` 和关卡号，卡片略向左倾。
- 右侧标题：黑色粗黑体中文配白底小框和方括号，下面一行红色大字（`PV-S-3` 或「明日方舟」），带横向扫描线和网格底，旁边小字副标题和 1/2/3 编号块。
- 红色像素方块散点、`HOW TO` / `HARD MODE` 小标签、`RHODES ISLAND` 条形标签、斜线填充块。
- 制作顺序（make-b）：b_013 白底 → b_014 刻度圆环 → b_015–b_018 立绘卡片 → b_019–b_022 标题初排 → b_029–b_030 背后大红英文 → b_037–b_045 标题改成红色像素化 `PV-S-3` → b_046 起补小标签、像素方块和网格细节。

## 复刻注意

- 不搬 ignoredone 的栏目标题、水印和字幕条；`RHODES ISLAND` 之类只用作通用 HUD 小字，不放官方标志。
- 立绘走现有 CDN；参考里的史尔特尔、麦哲伦立绘不入库。
- 两个案例分开做成两套模板，共用 HUD 组件，配色各自固定。

## 已做成的模板

| 案例 | 模板 id | 名称 | 主参考 | 默认立绘 |
| --- | --- | --- | --- | --- |
| A 墨绿 HUD | `garrison-terminal` | 墨绿终端 | `final-a.jpg`（16:9 裁切） | 麦哲伦「回味冰霜雪」`char_248_mgllan_kitchen#1` |
| B 白红 HUD | `garrison-record` | 红白档案 | `cover.jpg` 裁 16:9，文字排法按 `final-b.jpg` | 史尔特尔「缤纷奇境」`char_350_surtr_summer#9` |

- 视频画面是 16:10，封面在帧里横向 x 96–1828；比较时裁成 1732×974（y 偏移 53）再缩到 1920×1080。`cover.jpg` 取 (0, 80, 2560, 1520)。
- 两张参考里的立绘都是皮肤全景的半身截取。用 SIFT 把原图配准到参考，得到缩放、倾角和原点，再换算成卡片内坐标的 `imageScale / imageX / imageY` 和缩放原点：A 是 2.28 倍、−2.3°；B 是 2.17 倍、−5.1°（卡片 −3.5°，立绘再多转 1.6°）。
- 共用组件：`DecorArt.tsx` 的 `HudGrid / HudRings / HudDial / HudLines / HudPixels / HudScan / HudHatch`，`TextFaces.tsx` 的 `HudTag / HudIslandBar / HudPixelX / ScanText / FadeInkText`，配色在 `src/lib/garrisonHud.ts`。
- 字体替代：没有免费中文像素体和阿里妈妈数黑体，中文用思源黑体 Heavy，英文像素刻字用 Press Start 2P，红色大字用 Unbounded 900，英文名用 Anton。
- 刻度盘 0° 在正下方，往右侧增大，正上方 180 倒置，和视频里一致。
- 墨绿终端的中间大字用 CSS 蒙版挖横缝，周期约 0.032em、缝 0.009em；括号用两块真实 DOM 拼成直角，同样挖缝。
- 红白档案的史尔特尔头顶、角、右侧发尾、左袖出框：同一张立绘画两遍，下层在照片窗里裁切，上层套手描轮廓蒙版、不裁切，卡片底条再压在上层之上。
- 不做：A 底部字幕条和右上水印，B 原封面的「怎样学 / 明日方舟 / 平面设计」三行和 1/2/3 编号。

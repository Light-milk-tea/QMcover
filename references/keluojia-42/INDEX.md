做法拆解见 [doc/模组测评四列封面做法.md](../../doc/模组测评四列封面做法.md)，模板实现是 `src/templates/ModuleReview.tsx`（id `module-review`）。

- `main_16x9.png`：主参考，约 4:46 处全屏的 16:9 成品（1920×1080，底部压着一行字幕）；`main_960.png` 是同一帧缩到 960×540
- `frames/`、`keys/`、`subs/`、`hi/`：抽帧、参数对话框截取和字幕拼图，查数值用

以上图片和视频都不进 git。借鉴的是构图与图层职责，不搬成片里的四位干员、攻略组标志和署名。

## 不变量

1. 1920 四等分，每栏 480，无缝、无斜切。
2. 每栏从后到前：灰白竖向渐变 → 精二（渐变映射黑 → 代表色，曲线压暗，上亮下暗）→ 超窄体 `UNIT`（比代表色亮一档，上实下虚）→ 精一（清楚，取半身，脸落在 UNIT 下沿）。
3. 四栏合起来底部压暗，最底一条黄渐变向上淡出。
4. 主标题横跨四栏坐在暗带上：白字 + 黄期号，贴字暗边（距离 0、大小 25、85% 黑），下面垫一层横向动感模糊的黄光痕，两侧细方括号。
5. 新出第二模组的干员在栏右上挂屋顶形黄底 `2nd`；第一栏这期没有。
6. 加分项：底部暗带细点阵、贴边细黄框、一行很淡的字距极宽英文小字。

## 单张变量

干员、四栏代表色、期号、哪几栏有 `2nd`、攻略组标志。标志不进模板。

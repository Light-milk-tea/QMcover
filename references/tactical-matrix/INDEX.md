## 实现边界

新模板 id：`tactical-matrix`。默认死芒精英 0 立绘通过现有 CDN 加载，水平翻转后作为近景；底纹、网格、圆环和颗粒是独立生成的 SVG/DOM。默认墨底可替换为 AVG 背景。没有使用参考封面像素、原作者署名或官方标识。

默认文案：全息作战矩阵 / 四人 / LS-4 / 特种战演习。配色切换只改模板默认色，已手动调整的图层颜色继续保留。新模板不迁移、重置其他模板草稿。

## 紫色材质迭代（2026-09-16）

保留已确认的构图，按紫色原图逐轮对比和调整：

- 立绘改为灰紫中间调、偏粉的中性高光；左下局部紫色暗角让身体与背景融合，脸部保持明亮。
- 背景压回青黑，再加入低反差矿物细纹。早期凸凹滤镜和斑驳纹理过亮、过粗，后续收细并降低透明度。
- 角、发丝、衣领、胸口、袖口和衣摆加入局部虹彩，通过立绘 alpha 遮罩裁切；透明 PNG 导出测试确认轮廓外无染色。
- 调整左上与右下的紫色边光，加入低亮度雾带、细紫碎屑和少量带光晕的暖色火星。
- 胶片颗粒覆盖文字和人物。使用受控透明度的灰阶噪声，避免 overlay 在纯白文字上失效；SVG 调色明确使用 sRGB，避免线性 RGB 将背景抬亮。
- 新增「局部虹彩反光」「胶片颗粒」两个可隐藏、调节强度的图层。仅补入旧草稿缺少的新图层，不覆盖文字、位置、配色或已有隐藏状态。

最终检查默认稿、整页编辑器、html-to-image JPEG 和编辑器下载的 1920 × 1080 PNG，更新两份 960 × 540 WebP。

验证：`npx vitest run src/templates/TacticalMatrix.browser.test.tsx --browser.headless`，9 项通过。新增覆盖材质调节、旧稿保留和实际 PNG 虹彩遮罩边界。

### 平滑鲜艳字面（最终调整）

按用户最后确认的方向，收回过强的透色并去掉文字磨砂感：

- 文字使用普通合成，以近实心的亮白、粉紫和浓紫渐变构成字面，局部高光提供明暗层次；只保留少量底图染色。
- 不再采用 screen 混合，避免立绘、圆环和火星明显穿透字形。
- 胶片颗粒移到文字下方，默认稿与编辑器保持一致。新稿图层种子同步调整；旧稿通过既有原生图层顺序恢复流程更新，保留图层强度与用户的颜色、位置。
- 重新查看默认稿、整页编辑器与实际 PNG，更新两份缩略图。

验证：`npx vitest run src/templates/TacticalMatrix.browser.test.tsx --browser.headless`，12 项通过。PNG 测试检查轻微透色的上下限、两套主题色、最大颗粒强度下文字亮部无新增噪点，以及旧稿图层恢复。`npm run build` 通过。

### 文字边缘立体感

按用户要求给栏目名、人数、关卡和行动名增加细的右下缘阴影。使用两个真实 DOM 文字层：后层通过 SVG alpha 外轮廓滤镜生成阴影，前层保留平滑渐变和轻微透色。以实际字形的合并轮廓生成边缘，避免透明描边暴露中文笔画内部接缝；滤镜 id 按实例隔离。

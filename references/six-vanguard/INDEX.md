## 模板实现

- 模板 id：`six-vanguard`，名称「先锋六人」，实现：`src/templates/SixVanguard.tsx`。
- 单图构图依据：左侧多萝西精零近景、右侧阵容标题、下方超大斜体关卡码，灰黑人物叠影与网点纸纹，红色职业条和少量金色斜线。
- 默认文案：「先锋六人」「H9-5」「Vanguard」「PIONEER」；均可编辑。默认立绘：多萝西精英 0（`char_4048_doroth_1`）；背景：维多利亚街昼废墟，默认灰度调色，素材均走现有 CDN。
- 不复用参考图的职业图标、边缘品牌字样或整图。斜框、网点、纸纹和白点由 DOM/SVG 重建；文字上的金色集中在底部。
- 红标色块可改色和拖动；叠影、斜框、网点和白点可单独隐藏。叠影随主立绘更换。
- 默认稿与实际编辑器均用 Playwright Chromium 检查；实际 1920×1080 PNG 经 `html-to-image` 导出，缩略图由此 PNG 缩至 960×540 WebP。

## 文字与印刷材质迭代

- 保留已确认的人物和叠影位置。中文统一为粗宋体；关卡码对比 700～900 字重后采用 Outfit 750，调整数字内孔、横向比例与短横线宽度。
- 花体使用 WindSong（本地 WOFF2 与 SIL OFL 授权位于 `src/assets/fonts/`），以较细、舒展的手写字接近参考图的阅读关系。
- 完整矩形改成斜向内框与断角，边缘加虚焦 `PIONEER` / `VANGUARD` 字样；两层文字均可编辑，不复用 UP 品牌文字。
- 黑色编号章默认 `06`，可编辑，替代参考图的官方职业图标；红标补左侧渐隐拖尾。
- 金色粉尘为自行生成的透明纹理，生成器：`scripts/build-vanguard-texture.py`。没有取样参考图。白点采用固定随机序列，金线和白点位于人物后方，网点遮罩避开人物主体。
- 原图与每版画布均缩至 960×540 检查；同时检查整页编辑器、实际 JPEG 与 1920×1080 PNG 导出。
- 旧稿通过已有原生图层合并流程补齐新装饰，保留自定义内容与覆盖值；一般无需重置草稿。自定义字号和位移会继续优先于新默认。
- 浏览器验证：`npx vitest run src/templates/SixVanguard.browser.test.tsx --browser.headless`，覆盖长短文案的旋转字面边界、字体/编号编辑、图层调整和旧稿兼容。

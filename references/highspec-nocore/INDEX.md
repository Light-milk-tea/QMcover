## 构图备忘

系列目前只有这一张，先抠这张，不要用「无核封面一般都有金白两行」去补。视频标题「高配乱杀的MT-EX-8，看无核如何艰难取胜」不等于封面上的字；画面字是「众生行记」、关卡码「MT-EX-8」、棕色块「无核」、大字「首杀」。

| 类型 | 看到的东西 |
| --- | --- |
| **这张的骨架** | 浅色建筑剪影底。左上活动名宋体，下面一行小英文。中部一条通栏黑箭头（箭头朝左），里面超大白字关卡码。箭头下方：左棕色方块短词，右超大黑字。右侧一件近景机械载具，压住箭头右端和大字右缘。底部一条细线，中间署名。字和载具对坐，载具可以压住色块边缘，但不要挡死关卡码。 |
| **会变的** | 活动名、关卡码、色块里的词（无核）、大字（首杀）、色块颜色、右侧主体、背景场景。 |
| **不要搬** | 别人的整张封面、左上官方活动标、右侧这台官方载具贴图、`KirbySmost` / 「小鬼卡比」署名、视频标题里没画上去的「高配乱杀」「艰难取胜」。 |

字级：关卡码是无衬线超大白字，坐满黑箭头；色块里的词比关卡码小一档，仍是粗黑体；「首杀」比色块更高，黑体，几乎贴色块。英文小标是活动名底下的零件，不要做成居中海报签名。

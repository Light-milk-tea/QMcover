# 仅需一人封面参考

从 B 站「SWEEP分遣队」[通关AT-EX-8仅需一人（就是那个男人!）](https://www.bilibili.com/video/BV1awbAzSERP) 收集，只作构图参考。不要整图当模板底图。

封面后期：CPD。攻略：黑皇、zzz、xhx。

图片不进 git。原上传约 **1920×1440**（不是 16:9）；B 站卡片会中心裁成 16:9，对照骨架用 `_16x9` 那张。

这套和现成模板都不是同一构图，不要并进旧模板。

模板：`solo`，实现见 `src/templates/Solo.tsx`。只复刻左字组、暗红氛围和右立绘；不搬整张封面、UP / 后期署名。默认关卡写成 QM-EX-8，默认立绘用酒神精英 0（精二立绘自带场景）。

## 构图备忘

系列目前只有这一张，先抠这张，不要用「单人封面一般都有红框 / 水印」去补。视频标题「通关AT-EX-8仅需一人」不等于封面上的字；画面主标是「酒神单人」，关卡码是 AT-EX-8，底下一句 `ONE OPERATOR ONLY`。

| 类型 | 看到的东西 |
| --- | --- |
| **系列不变量** | 暗红烟底。左中字组：上sans关卡码、中宋体「××单人」压一条黑带、一条细白线、线下英文小标。右近景半身立绘。立绘低于全部正文。 |
| **会变的** | 标题（酒神单人）、关卡码（AT-EX-8）、主立绘、背景场景。 |
| **不要搬** | 别人的整张封面、参考 UP / 后期署名、官方标。 |

字级：关卡码超大号黑体（不是细长 Oswald），几乎水平坐着；主标题宋体黑压在贯穿画布的水平黑条上，不要缩成标题周围的短方框；条下先细白线再一条暗红线；英文标对准标题居中，不要整组斜拧。

红雾是默认骨架件，可在右侧背景栏关掉或调透明度，默认 74。光效是独立图层，默认打在立绘后面，特效栏可选立绘上 / 立绘下。左上角默认放方舟标。涡旋、斜带和火星已从默认去掉。默认不要红宽带和暗纹细线。默认背景用哥伦比亚 38_g17_1，不要墨底。

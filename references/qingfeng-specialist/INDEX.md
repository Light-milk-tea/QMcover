## 构图备忘

系列目前只有这一张，先抠这张，不要用「三特种封面一般都有蓝斜带 / Persona 梗」去补。视频标题「芋圆洁如果未来是你的就...」不在封面上；画面主标是「三特种」，关卡码是 `H16-4`。

| 类型 | 看到的东西 |
| --- | --- |
| **系列不变量（待多图验证）** | 白底细颗粒底 + 克莱因蓝几何斜切：右上一条粗蓝斜带、右下蓝色切面、左下一块黑色斜三角。左半身立绘带蓝色偏移重影轮廓，立绘低于右字组。右侧超大粗黑字组：中文阵容名压超大拉丁关卡码。 |
| **会变的** | 阵容名（三特种）、关卡码（H16-4）、主立绘、斜带角度与位置。 |
| **这一张的特例 / 别人的壳** | `>Persona!`、`MAKOTO YUKI`（女神异闻录 3 结城理梗，随本期主题走，不要当模板固定件）；右上小雪花/菜单小图标；角色身上的 ID 卡等定制细节。 |
| **不要搬** | 别人的整张封面、Persona 品牌字样、参考 UP / 攻略 / 后期 / 封面作者署名、官方标。 |

字级：「三特种」是超粗黑无衬线，几乎占满右侧上半，「三」左侧带两横短杠装饰；蓝色斜体 `Specialist` 小字斜插在中文与关卡码之间。关卡码 `H16-4` 更大，黑色字面带蓝色渐变 / 扫光，连字符位置是一颗空心三角警示标，数字 `6` 圈内也叠了一颗小三角——复刻时按「关卡码可换 + 三角警示标为构图零件」处理，不要写死 H16-4。

立绘：左侧近景半身，外轮廓有一层错位的蓝色重影（RGB 分离感），身后有浅金 / 浅灰的放射状武器残影，整体压在白底上，右侧被字组遮住时立绘在下。

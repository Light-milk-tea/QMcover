## 构图备忘

对着四张并排读，还没写成模板。

| 类型 | 看到的东西 |
| --- | --- |
| **系列不变量** | 超大号两行字：上行阵容条件（N特种 / 三特种 / 六特种…），下行关卡码（H15-4 / H12-3）。立绘占另一侧。一层细线 / 圈 / 色块 HUD。 |
| **会变的** | 左文右图（01–03）还是左图右文（04）。单人还是双人。红花体、红圈靶、大红 Z、青绿笔触。灰白工业、暖纸、全灰+红、暗底青绿。 |
| **不要搬** | 莱茵实验组标、罗德岛标、封面署名、别人的整张封面。 |

字和立绘对坐；立绘仍应低于全部正文。视频标题里的词（「吹一波琳琅诗怀雅」「终结循环时代」）不等于封面上的字。

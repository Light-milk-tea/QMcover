## 构图备忘

系列目前只有这一张，先抠这张，不要用「无核封面一般都有金白两行」去补。视频标题「精一四星队」不等于封面上的字；画面主标是「四星无核」。

| 类型 | 看到的东西 |
| --- | --- |
| **系列不变量** | 暗底拼贴。左中斜抬黑体大标题 + 浅米色梯形条关卡码（条左侧三点）。右近景彩色立绘。立绘后斜放一圈金框，框里是俯视地图。左上灰度干员剪影 / 提线偶。底下一层棋盘格 + 青绿线框。字和立绘对坐，立绘低于全部正文。 |
| **会变的** | 标题（四星无核）、关卡码（SS-8）、主立绘、框里那张地图、背景灰度干员和英文小标。主立绘的衣服色会带一套点缀色（这张是青绿）。 |
| **不要搬** | 别人的整张封面、框里的实机录像截图、参考 UP / 封面作者署名、官方标、具体某张灰度立绘当贴图。 |

字级：主标题超大号黑体、微上旋（大约 15°），关卡码同角度坐在米色条上。英文小标是背景零件，不要做成居中海报签名。

金框和提线偶是这张的骨架件，不是可有可无装饰；做模板时用几何框 + 可换底图，不要手绘花边冒充雕花。

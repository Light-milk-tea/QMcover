# 无核五人封面参考

从 B 站「永恒的信标」[【SN-EX-8镀层】无核 五人](https://www.bilibili.com/video/BV1KZ4y1a7MM) 收集，只作装饰对照。封面后期致谢卡比佬。

图片不进 git。原上传约 **1728×1080**。

几何饰件：四角星、雷达弧、斜刻度、链节。方舟标是排版复刻的中文标（绿线下划「方舟」），不是官方 PNG。三周年纪念章和 UP 署名花边不搬。

装饰实现见 `src/data/decorations.ts` 的 `ark` 组，画布件在 `src/canvas/LayerChrome.tsx`。

# 偶像大字封面做法

根据 FM·Azuki [《「咔」封面教学：做一张好看的视频封面吧 第二期~》](https://www.bilibili.com/video/BV17Z4y1z7RB/) 整理。本地成片在 `C:/Users/23625/Downloads/` 下（1080p，23 分钟直播教学，无字幕轨），主参考是约 23:00 的成品帧 `references/idol/main_frame_2300.jpg`。

这期他做的是一张 K-ON 角色「琴吹紬」的单推封面。做成 QMcover 模板时，复刻下面的构图和图层职责；不搬 K-ON 官方 LOGO、「けいおん！」、FM·AZUKI 品牌带和官方 Q 版小人图，装饰带默认文案换成普通可编辑文字。

已做成模板「偶像大字」（id `idol`，`src/templates/Idol.tsx`），PS 步骤和模板图层的对应见文末。

## 成品长什么样

16:9 画布 **1920×1080**，米粉色纯底。从后到前：

1. 背景纯色。PS 里是 #F1E0D2，再过一遍 Camera Raw 提亮，成品约 #F6E5DD～#FCF3EA 一带，下缘略偏粉、中上偏黄白。
2. 上、下两条**重复文字带**：黑底白小字横贯画面（视频里是 `FM·AZUKI` 和 `VOL.003` 的机械重复，模仿电台呼号/杂志刊头）。
3. 两行超大**空心英文大字**：角色罗马音 `KOTOBUKI`（画布约 35% 高）和 `TSUMUGI`（约 70% 高，更大），淡樱粉描边（约 #F5CFED），总占约六成画面。
4. 立绘居中偏右，头部压过空心大字，形成镂空层次。
5. 橙红实心主标题 `封面 教程`（≈#A24A28）两个词左右分开、让开人物，位于最上层，永远不被挡。
6. 四角 Q 版小人、右侧竖排手写小字（`special with` 手写橙字）。

这一期的文案是 K-ON 的内容，不是骨架。换成任一万干员：英文名两行进空心大字、主标题换栏目名、上下带换普通可编辑文案、四角换小人库里的 Q 版小人。

## 关键技法

- **空心大字** = 文字填充 0% + 描边 + 渐变叠加。浏览器里对应 `-webkit-text-stroke` + 透明填充（项目肉鸽模板 `ISW-NO` 已验证这套能过 `html-to-image` 导出）。
- **立绘压空心大字**：人物先放，镂空字放人物之下，头部压字但主标题永远在人物之上。这是这张封面的空间层次核心。
- **画笔取色**：主标题橙红是从旧成品 psd 上取色的，不是凭感觉配色。模板里把色值固化成默认。
- 装饰带、背景调色都围绕「粉 + 樱紫 + 橙红」的暖糖果色调走，混合模式只做局部调色，不是滤镜堆砌。

## 映射到模板（PS 步骤 → QMcover 图层）

| 视频里的做法 | QMcover 模板 |
| --- | --- |
| 背景色块 #F1E0D2 + Camera Raw 提亮 | 画布纯色，默认约 #F7E7DE，编辑器给「背景色」取色器 |
| `KOTOBUKI` / `TSUMUGI` 空心字 | `name-top` / `name-bottom` 两个文字层：透明填充 + 樱粉描边（双层真实 DOM 做厚度），默认取点选干员的英文名 |
| 橙红主标题 `封面 教程` | `head-l` / `head-r` 两个文字层，绑定标题字段按词对半拆，思源黑体 900，默认 #A24A28，z 最高 |
| 立绘（抠图大图） | `operator` 立绘层，居中偏右、头压空心字 |
| `FM·AZUKI` / `VOL.003` 重复带 | `band-top` / `band-bottom` 两个可编辑文字层：小字无限重复排一条，黑半透明底；`band-bottom` 默认跟期号 `VOL.001` |
| 四角 Q 版小人 | `chibi-tl/tr/bl/br` 四个小人层，走现有基建小人库（`source: "chibi"`），默认开 |
| 角落手写小字 | `hand-note` 手写体小字，默认 `special with` |

## 明确不搬的

K-ON LOGO、「けいおん！」、FM·AZUKI 品牌字样与装饰带原文、官方 Q 版小人立绘、视频里的具体角色图。装饰带文字默认用「QM 封面」一类普通可编辑文案代替。

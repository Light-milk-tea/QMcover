# 模组测评四列封面做法

根据剋珞迦 [《#42 借明日方舟浅谈一张封面的做法》](https://www.bilibili.com/video/BV1KrSSBGESg/) 整理。本地成片在 `references/keluojia-42/BV1KrSSBGESg.mp4`，约 4 分 53 秒。这期讲的是他给海嗣攻略组重制的「模组测评」封面，只覆盖这一类海报式封面，不是通用封面教程。

做成 QMcover 模板时，复刻下面的构图和图层职责。不要把这张成图、攻略组标志或成片里的干员贴进模板。

已做成模板「模组测评」（id `module-review`，`src/templates/ModuleReview.tsx`），PS 步骤和模板图层的对应见文末。

---

## 成品长什么样

16:9 画布 **1920×1080**，四条等宽竖栏，每栏 **480×1080**（`1920/4`）。

每一栏从后到前是：

1. 一条竖向的灰白渐变，把精二背后的空档填上。
2. 精二立绘：暗部收成黑色，亮部收成这个干员的代表色，并且上亮下暗。
3. 一个大号英文 `UNIT`，颜色比代表色更亮，不挡住精二的脸，左右比这一栏略窄，同样上亮下暗。
4. 精一立绘压在最前，脸和上半身保持清楚。

四栏拼完以后，下沿整条压暗，最底下再铺一条黄渐变。主标题坐在这条暗带上，横跨四栏，是画面里最大、最亮的一层。有「第二个模组」的干员，在栏内上方加一块黄底 `2nd`。标题外再加发光、投影、方括号、点阵、自己的标志和细外框。

这期成片的标题是 `[模组测评 #3]`：`模组测评` 白色，`#3` 黄色。四栏代表色大约是红、紫、蓝、橙。第 1 栏没有 `2nd`，后三栏有。这些是这一期的内容，不是骨架。换期就换干员、代表色和期号。

---

## 这套做法服务什么

作者把标题放在图层最上方，也放在画面最底部。人物、背景字、色块都是为了把大标题托出来。代价是人物下半身和一部分脸部重点会被压暗、被字挡住。为了缩略图里一眼能读，要做减法：少装饰，少和标题无关的英文。

他明确说，这不是「以人物为中心」的封面，是为了信息效率把标题当主体。终末地直播施工图、莱茵生命队那种大字配单人的封面，不要套这套四列做法。AMV 一类封面也不在这期里。

早期被退回的版本是四张竖卡加人名，下面一条灰条写「模组测评」。问题是简陋、不好看、不好读。重做时的需求只有三句：

- 放四位对应模组的干员立绘。
- 大标题就是「模组测评」。
- 黑体、干净，删掉没有信息的装饰。括号里他写了「仅本次的封面」，所以花边、英文副标不要自行加回去。

## 动手前准备

| 项目 | 视频里的做法 |
| --- | --- |
| 立绘 | [PRTS](https://prts.wiki) 下载基础立绘。每栏用同一干员的精一和精二，不要用皮肤大图或宣传图 |
| 中文标题 | MiSans Bold，作者写成 `misans-bold`，搜索引擎可下到字体文件 |
| 栏内英文 | Morganite SemiBold，作者写成 `MORGANITE-SEMIBOLD`。文案就一个词：`unit` |
| 16:9 | 按 1920×1080 做。这期拆解用的就是这个比例 |
| 4:3 | 首页推荐是 4:3，个人空间是 16:9。有余力就做两份。4:3 不是把 16:9 拉高，而是把画布扩成 **1920×1440** 再排 |

`2nd` 只加给这一期新出了第二模组的干员，不是四个人都贴。

---

## 图层职责

一个干员一个文件夹。这一栏后面的蒙版、调色、背景字都进同一个文件夹，方便复制成另外三栏。

单栏从下到上：

```text
干员文件夹
├─ 矩形：栏宽渐变底（灰 → 白）
├─ 精二立绘
│  ├─ 渐变映射（黑 → 代表色）
│  └─ 曲线（压暗）+ 蒙版（上白下黑）
├─ UNIT（Morganite SemiBold）+ 同样的上下渐变
└─ 精一立绘
```

四栏都放进一个「立绘」文件夹。这个文件夹上再挂：压暗曲线和它的上下渐变蒙版，用来给标题留出底部暗带。最底部另做一条黄渐变，不要塞进某一栏。

全画布最上：

```text
外框、标志
标题（MiSans Bold）+ 投影 + 方括号
标题发光（在标题下面）
2nd 角标
点阵
黄色底渐变
立绘文件夹（含四栏）
```

立绘永远在标题下面。

## 做第一栏

后面三栏按同一顺序复制，只换立绘和代表色。

### 1. 切出等分竖栏

新建矩形，宽高直接写成：

- 宽度 `1920/4`（Photoshop 会算成 480 像素）
- 高度 `1080` 像素
- 圆角 0，不从中心绘制

这个矩形先当裁切模具，后面还会复制一份当渐变底，先留着。

把精一、精二放进画布，给这一对立绘新建文件夹。之后这一栏的操作都放进这个文件夹。

按住 Ctrl，点击立绘下方那块矩形的图层缩略图，载入选区。选区盖到立绘文件夹上，做成图层蒙版。蒙版把两张立绘切成一栏宽。矩形本身可以先隐藏。

### 2. 精二收成代表色

只处理文件夹里靠后的那张精二。

打开渐变映射。菜单 `图像 → 调整 → 渐变映射`，或图层面板底部的调整图层里选 `渐变映射`，两个入口都可以。调整图层要剪贴到精二上，不要染到精一。

渐变映射对话框：

| 项 | 值 |
| --- | --- |
| 名称 | 自定 |
| 类型 | 实底 |
| 平滑度 | 100% |
| 色标 | 两个。左端纯黑，位置 0%；右端是这个干员的代表色，位置 100% |
| 中间滑块 | 留在色条中部，先不要另加色标 |

暗部全部换成黑色，亮部全部换成代表色。代表色用吸管从人物头发、衣服的主色上吸，再手动拧到够纯。这期第一栏吸出来的是深红色。不要用原画自己的杂色。

### 3. 把精二压暗，再做成上亮下暗

在精二上新建曲线调整图层，同样剪贴。视频里的曲线是 RGB、自定：

- 左下角的黑场锚点留在原点附近，没有往上抬。
- 右上角的白场锚点往左下拉，整条曲线落在对角线下面。
- 效果是精二整体变暗，高光也被压住。画面没有停在能读出「输入 / 输出」数字的那一帧，不要自己填一对整数冒充视频参数。压到背景人影还认得、但明显暗过前景精一即可。

这时整张精二都暗了。接着只让上半保持亮、下半保持暗：

1. 选渐变工具。在渐变编辑器里把渐变调成：左侧色标不透明度 100%、纯黑；右侧色标不透明度 0、没有颜色。类型实底，平滑度 100%。
2. 给刚才的曲线图层新建蒙版。新蒙版默认是白的，曲线仍然全图生效。
3. 点中这块蒙版，用渐变工具从上往下拉。

蒙版上黑隐藏曲线、白显示曲线。顶端被涂成黑，精二恢复亮度；底端仍是白，压暗留在下面。拉完应是上亮下暗，而不是一整条均匀发灰。

### 4. 用一块渐变把精二背后垫厚

复制刚才用来裁切的矩形，粘贴进同一个文件夹，放到精二后面。

打开这个矩形的填充，改成渐变。在填充面板里右键渐变条，进入渐变编辑器。视频里这块渐变叫「灰色、白色」：

| 项 | 值 |
| --- | --- |
| 类型 | 实底 |
| 平滑度 | 100% |
| 色标 | 左端黑或深灰，右端白 |
| 样式 | 线性 |
| 角度 | 90°（竖向） |
| 缩放 | 100% |
| 与图层对齐 | 勾上 |

它的作用是把精二背后的纯色空档做成有深浅的底，不是第二张插画。

### 5. 加上 UNIT

字体 Morganite SemiBold，打 `unit`。这款字很窄、很高，会铺满一栏的中上段。

取色规则：在代表色的基础上再提亮，必须比背后的精二更亮。第一栏就是比那块深红更亮的红。不要用纯白，也不要和精二同色，否则字会溶进背景。

字号和位置：

- 不要挡住精二的脸。
- 左右比这一栏的裁切宽度再小一圈，左右留出底色。
- 用和第 3 步相同的办法做上亮下暗：要么给文字图层蒙版，要么用同样的黑到透明渐变往下拉。字的下半应淡进底部暗区。

第一栏到这里就完成。另外三栏复制这个文件夹，换精一、精二和代表色。`UNIT` 的字色跟着新的代表色再提亮一档。

## 四栏拼完之后

### 给标题留出底部暗带

在包含四栏的立绘文件夹上新建曲线，把整体亮度压低。再沿用前面的蒙版渐变：上亮下暗，暗的部分集中在底部标题将要落下的地方。脸仍要留在亮区里。

曲线的具体锚点视频没有单独标数字，意思是「底部让出一块暗底」，不是把四个人全部压黑。

### 最底下一条黄渐变

在画布最下方做一条黄色渐变，盖住标题背后的那一截，不要拉进脸。

渐变编辑器：

| 项 | 值 |
| --- | --- |
| 名称 | 自定 |
| 类型 | 实底 |
| 平滑度 | 100% |
| 左端 | 黄色，不透明 |
| 右端 | 不透明度 0，色块呈棋盘格 |

在画面上从下往上拉，底边是黄，向上淡出。这是标题底下的色带，不是每一栏各做一条。

### 可有可无的调色

作者把这几项叫「影响不大」，叠在立绘文件夹外面。图层组里能看到「废土搭配」。画面上读到的数值是：

| 调整 | 数值 |
| --- | --- |
| 自然饱和度 | 自然饱和度 +35，饱和度 −15 |
| 色彩平衡 | 中间调。青/红 +8、洋红/绿 +8、黄/蓝 +8，勾选「保留明度」。三项同向各加 8，基本互相抵消，画面几乎不偏色 |
| 亮度/对比度 | 亮度 0，对比度 +30 |

这三项是最后的统一色调。某一栏的代表色不对，回到那一栏的渐变映射改，不要靠这三块硬拧。

### 2nd 角标

只给新出了第二模组的干员加。这期是后三栏，黄底、黑字 `2nd`，放在该栏上半、`UNIT` 附近，不压脸，也不要做成和主标题一样大。

### 主标题

字体 MiSans Bold。`模组测评` 用白色，期号 `#3` 用黄色。标题在最底层的位置、最上层的图层，字号大到横跨四栏，底部切进黄渐变里。

作者说：细节要求不高的话，标题摆上就算做完。下面的发光、投影、括号、点阵、标志和外框是加分项。

---

## 标题上的加分项

### 发光

1. 复制标题，把副本转为智能对象。
2. `滤镜 → 模糊 → 动感模糊`。成片是一道横向的光痕。角度和距离那一帧没有停在能读数字的对话框上，按「横过来、拉出一条光带」调，不要猜一个距离值。
3. 新建一个空图层，和模糊后的智能对象一起选中，合并。这样光痕变成普通像素，方便加样式。
4. 图层样式里加「颜色叠加」，混合模式正常，颜色改成黄。不透明度字幕只说「调整透明度」，按光不抢标题来收。
5. 这层放在清晰标题的下面。

### 投影和括号

发光做好后，给清晰标题加投影，并加上装饰用的方括号，成片是 `[模组测评 #3]`。

投影对话框里能读到的是：

| 项 | 值 |
| --- | --- |
| 混合模式 | 正常 |
| 颜色 | 黑 |
| 不透明度 | 85% |
| 角度 | 90°，使用全局光 |
| 距离 | 0 |
| 扩展 | 0 |
| 大小 | 25 像素 |
| 杂色 | 0 |
| 图层挖空投影 | 勾上 |

距离是 0、大小约 25 像素，所以这是贴着字的一圈暗边，不是往旁边甩出去的长影子。

### 点阵

作者说加分项是「一层发光和点阵图形」，发光有逐步操作，点阵没有单独的滤镜讲解。成片下半能看到细点，范围在标题暗带里。做的时候只在底部暗区铺一层低对比点，不要铺满脸。

### 标志和外框

最后放上自己的攻略组标志，再加一圈细外框。视频用的是海嗣攻略组的标志，模板里换成使用者自己的，不要把那个标志描进来。

## 4:3 的另一份

`图像 → 画布大小`，改成 **1920×1440**，再按上面的顺序排。多出来的高度用来拉长四条竖栏和底部暗带，不要把 1920×1080 的成品直接拉伸。

栏宽仍然可以按画布宽度四等分。若画布仍是 1920 宽，每栏还是 480。高度改成 1440 后，矩形模具、蒙版和上下渐变都要按新高度重拉，不能把 1080 的蒙版原样贴上去。

---

## 做到哪一步算像

并排看时，先看这几件，不要先看发光和点阵：

1. 四栏等宽，栏与栏之间没有缝，也没有斜切。
2. 每栏都是「色块化的精二在后，清楚的精一在前」，精二上亮下暗。
3. 每栏有一个比底色更亮的窄体 `UNIT`，不挡脸。
4. 底部是一整条暗带加黄边，主标题白字加黄期号，压住人物下半。
5. 标题在所有立绘上面。

发光、投影、`2nd`、点阵、外框都是在这个骨架成立之后再加。骨架错了，后面越加越不像。

## 在 QMcover 里对应哪些图层

| 视频里的步骤 | 模板图层 | 怎么改 |
| --- | --- | --- |
| 渐变映射的代表色 | 第 N 栏代表色 | 编辑栏「四栏代表色」，或在图层里选中后调色；精二和 UNIT 一起变 |
| 精二 + 曲线压暗 | 第 N 栏精二 | 选中后从立绘库换图、拖动、缩放；给同栏精一换人时它会自动换成这位的精二 |
| `UNIT` | 第 N 栏大字 | 编辑栏「栏内大字」，四栏共用；字体是 Six Caps（Morganite 的免费替代） |
| 精一 | 第 N 栏精一 | 选中后点干员头像，默认用精一立绘；第 1 栏就是编辑栏里的主立绘 |
| `2nd` | 第 N 栏角标 | 编辑栏「角标文字」；不需要的栏在图层里隐藏，第 1 栏默认隐藏 |
| 立绘文件夹的压暗曲线 | 底部压暗 | 可调不透明度 |
| 废土搭配（自然饱和度、对比度） | 固定叠在四栏精一上 | 不单独成层。精二、代表色和 UNIT 是照着调完色的成图取的，不再重复调 |
| 黄渐变 | 底边黄渐变 | 可改色、调不透明度 |
| 标题 + 投影 + 括号 | 主标题、期号、左括号、右括号 | 编辑栏「主标题」「期号」；字多了整行自动缩小 |
| 发光 | 标题光痕 | 可改色、调不透明度 |
| 点阵、外框 | 底部细点阵、细外框 | 可改色；不要就隐藏 |

标题字体用思源黑体 Bold 代替 MiSans Bold。攻略组标志不在模板里，用「添加 → 图片」放自己的。4:3 版本还没做。

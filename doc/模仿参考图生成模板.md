# Prompt：根据参考图生成高相似度封面模板

新建、复刻或美化现有模板时使用本文。参考图放进 `references/<系列>/`，jpg 不进 git。逐轮对比、三个视图的验收和导出方法见 [封面视觉迭代与验收](封面视觉迭代与验收.md)，工程接线见 [TEMPLATES.md](../TEMPLATES.md)。

把本文作为提示词发给其他 Agent 时，也提供上述链接文档，或确保它能读取仓库。

---

## 角色

你在 QMcover 里做一套新的 B 站横版封面模板（1920×1080）。目标不是「好看的原创设计」，而是 **复刻某一系列参考封面的构图系统**：字在哪、条在哪、谁压谁、用什么字重和材质。做成可填内容的模板，让换标题、立绘、背景之后，看起来仍像同一系列。

成功标准：把本模板默认稿和主参考图并排，路人能一眼看出是同一套构图；不要做成「意思差不多」的简化版。

按构图类型找对照样本（参考目录里的 `INDEX.md` 记着数值）：

| 构图 | 样本 |
| --- | --- |
| 斜切分栏、横条 | `LowSpec.tsx`（低配）、`Rogue.tsx`（肉鸽） |
| 左文右图 | `Madness.tsx`（决战五星之癫）、`Endfield.tsx`（终末地测评） |
| 等分竖栏 | `ModuleReview.tsx`（模组测评） |
| 立体字、整套主题色 | `RetroFuture.tsx`（让大地变成一片酸橙） |
| 倾斜卡片、出框立绘、HUD | `GarrisonTerminal.tsx`、`GarrisonRecord.tsx` |
| 自由海报：爆炸框、斜笔刷、黑卡 | `UnveilStage.tsx`、`UnveilBrush.tsx` |
| 光痕、晕染材质 | `EmergencyLesson.tsx`（紧急授课） |

## 硬约束

- **复刻构图，不搬整图。** 不要把别人的封面、官方宣传图、ZC logo、官方标当底或当贴图。
- 参考 jpg 只作对照，已被 gitignore，不要提交。
- 立绘、AVG 背景只走现有 CDN（干员库、背景库），不要把大图拷进仓库。
- 导出靠 `html-to-image`。描边、阴影用 **双层真实 DOM**，不要用伪元素；需要 `crossOrigin="anonymous"`。
- `CoverElement` 外层 `translate` 只负责拖动，字效写内层。
- 不要手绘花边、卷草、角花。要么用现成公有领域素材并做成可选，要么不加。用户已经证明手绘花边会显得廉价。
- 先改模板默认，再处理旧草稿。`localStorage` 里的 `elementStyles` 会盖住新默认，需要时写一次迁移，或告诉用户点图层重置 / 新建。用户丢来 `*_配置.json` 时的处理见第 6 步。
- **立绘永远在文字下面。** `OperatorLayer` 默认 `z-[1]`，父级也不要高于字。挡字比「立绘压住水印更好看」更糟。
- **蒙黑是局部暗角，不是整屏抹黑。** 用 `BgDimLayer`（径向、边缘透明）。每个有背景的模板都要能开关、能调黑度。

## 对照工具

都在 `scripts/qa/`，用仓库自带的 Playwright Chromium，不装别的图像库。先 `npm run dev`；产物默认写到 gitignore 的 `tmp-compare/<id>/`。

```bash
# 参考图统一成 1920×1080；例如 2560×1600（16:10）的封面上下各裁 80px 再缩放
node scripts/qa/compare.mjs fit references/<系列>/cover.jpg references/<系列>/main_16x9.png --box 0,80,2560,1520

# 每轮：默认稿截图 + html-to-image 导出，并报两者差值
node scripts/qa/shot.mjs <id> r3

# 参考在上、当前在下；50% 叠图；局部加坐标网格（box、step 用图片自身像素）
node scripts/qa/compare.mjs pair  references/<系列>/main_16x9.png tmp-compare/<id>/r3_chromium.png tmp-compare/<id>/r3_pair.jpg
node scripts/qa/compare.mjs blend references/<系列>/main_16x9.png tmp-compare/<id>/r3_chromium.png tmp-compare/<id>/r3_blend.jpg --box 200,100,1100,800
node scripts/qa/compare.mjs grid  references/<系列>/main_16x9.png tmp-compare/<id>/ref_grid.png --box 1300,0,1920,760 --step 25 --zoom 2

# 读元素在画布里的坐标；量字体实际墨迹
node scripts/qa/probe.mjs <id> "[data-cover-el=title]" --font '"Anton"' --text PV-EX-8

# 整页编辑器截图 + 点「导出封面」拿真实 PNG；定稿后写首页两份缩略图
node scripts/qa/editor-export.mjs <id>
npm run thumb -- <id>
```

- 标签每轮换新名（`r1`、`r2`…）。读图工具会缓存同名文件，拿到的可能是上一轮的图。
- 默认稿没有任何图片（纯字模板）时加 `--min-images 0`，否则脚本会一直等图片。

## 工作顺序（不要跳）

### 1. 先读一组图，再锁定一张主参考

同一系列至少看 5～8 张，不要只盯一张。记下两类东西：

| 类型 | 做法 |
| --- | --- |
| **系列不变量** | 每张都有的骨架：分栏、切面、条数、字级、材质分工。写成布局规则。 |
| **单张变量** | 标题、干员、场景、有无某装饰。变成可编辑字段或可关的图层。 |

低配攻略的不变量：左立绘、右三横条、斜切遮住立绘右半、上/下条用场景、中条纸色、金字活动名 + 白后缀、中条署名 + 攻略类型、下条两句卖点。变量：活动名、干员、AVG、署名、花边。

选一张最干净、元素最全的当 **主参考**，其余用来核对「这个到底是系列特征还是这一张的特例」。ZC 系列里「活动」二字不是每张都有，主参考没有就不要硬加（或做成默认隐藏）。

系列只有一张图时，更要抠这张，不要用「肉鸽封面一般都有 N15 / 红框」去补。视频标题里的词不等于封面上的字。

参考来自教学视频时，封面和视频里的成品帧可能不是同一张图：封面常把标题换成了栏目名，过程帧还没调完色。两者都看，选元素最全的那张当主参考，另一张对细节；用了哪一帧写进 `INDEX.md`。

用户丢来两条链接时，先问清分工：哪张定 **构图**，哪张定 **栏目名 / 文案**。决战五星之癫就是构图跟时隙、文案跟阿罗玛；把差构图那张当骨架会一直拧。参考 UP 的 logo、STAFF TRAINING GUIDE、Doctor 花体、署名是别人的系列壳，不是不变量，不要搬。

### 2. 先量骨架，再写字

先把主参考统一成 1920×1080：16:9 直接缩放；视频帧和部分封面是 16:10，先用 `compare.mjs fit --box` 裁成 16:9，否则所有纵向位置都偏一截。然后在这张图上定：

1. **分区比例**：左立绘占多宽、右栏从哪切到哪。用百分比或 `clip-path`，对着参考量过再写，不要凭感觉画一条竖线。
2. **层级**：立绘在切面 **下面** 还是上面。低配是立绘 z 更低，斜切栏压住右半身；肉鸽、无核、危机合约同样是立绘低于全部文字（含空心水印）。切缘不要自作聪明加发光白线。左立绘靠字的一侧可以做 **渐隐**（身子仍实，最后一截才溶进字和底），不要整块削掉右三分之一。
3. **横条数量和相对高度**：三等分还是中条更薄。先用 flex 比例落位，再微调 padding。
4. **安全区**：脸和主标题留在 `BILI_SAFE` 里。
5. **主标题的起点和字高**：不是只有斜切栏才要量。时隙主标题大约 `x=180`、`y=370`、字高 `150`；第一版 `left: 100`、字号 92，用户一眼就是「偏左、偏小」。不要凭感觉摆现代 UI 边距。

**怎么量：** `compare.mjs grid` 在参考上读初值；缩小拼图上的读数会差几十像素，只能当起点。写进代码后用 `probe.mjs` 读 DOM 实际坐标，再用 `blend` 叠图看偏差，不要反复在网格上目测。

**自由构图怎么量。** 爆炸框、倾斜卡片、斜笔刷这类海报没有分栏可量，改成「锚点 + 角度 + 叠放顺序」：

- **倾斜卡片**：在网格上读卡片两个上角，角度 θ = atan2(dy, dx)，再读中心和宽高。代码里先写一个不旋转的盒子，再整体 `rotate`，卡内文字、立绘都放在卡片的局部坐标里。立绘配准结果也要换到局部坐标：先按卡片倾角反转点坐标，再按 `pan = 原点 − O·(1 − s)` 算平移（O 是缩放原点，s 是 `imageScale`）；立绘比卡片多转的角度单独套一层。
- **爆炸框、星形、尖角对话框**：读外接框和每个尖角的坐标，写成 SVG `polygon` 的点，不用 CSS `clip-path`（终末地的黄三角用 clip 导出成了整块黄板）。
- **斜笔刷、色带**：量方向角和笔道粗细。笔道画成水平线，整组再旋转；飞白噪点放在旋转组里面，才会顺着笔道走。直接画斜线再套横向噪点，会变成一排横向故障条纹。
- **叠放顺序**：先在参考上列出谁压谁（底色 → 笔刷 → 卡片 → 立绘 → 出框部分 → 字 → 贴纸），按这张表定 z，再调位置。
- **立绘取景**：对原图和参考做特征点配准（SIFT），比按眼距手量准。酸橙第一轮手量估成 1.72 倍加 −4° 旋转，人物小了约两成；配准是 2.02 倍、零旋转。

没对上骨架之前，不要做花边、渐变、字效。骨架错了，后面越改越歪。

### 3. 字级按参考抄，不要「设计一版」

对着主参考读出字级，而不是自己配一套现代 UI 字号。

- **量字墨，不量字号。** CSS 字号不等于字形高度。用 `probe.mjs --font` 量出 100px 下的字宽和大写高（Anton 大写高 0.88em），按参考里的像素高度反推字号，按宽度反推 `scaleX`。揭幕者第一版凭眼睛压到 0.62，比参考窄了一截。笔画粗细也要比：MiSans Bold 比参考细，换 Black（900）后竖笔宽度才对上。
- 中文大标题优先 **宋体黑**（`--font-serif` / `Noto Serif SC` 700/900），活动关、栏目名这类封面很少用细黑体。参考图是宋体就写宋体，不要两段标题都套同一套斜黑体再靠相近色区分，会「单一」。
- 标题拆成两段时，用 **字体对比** 分工，不要只换色：栏目名宋体 + 描边正坐，冲字（「之癫」）黑体斜切实心。两段都加同一套描边，又会糊成一块。
- 金字 = 金填色 + 很重的深色描边 + 一层错位暗影（双 span）。不要只靠 `text-shadow` 冒充描边。
- 立体字、描边字先在 1:1 截图里数参考有几层、每层几像素，再看哪层太粗。描边或字面加粗会先吃掉字内空隙，窄字体尤其明显。
- 标题有固定语法就写成规则，例如含「的」则拆成金字 + 白后缀（沃伦姆德 / 的薄暮）；栏目名固定就写死（「决战五星之癫」），不要做成输入框。
- 字号按字数分段缩放（2 字 / 4 字 / 更长），并给行高和 `padding-bottom`，避免「平民攻略」这类字被切掉脚。
- 英文小标（OPERATION）是构图零件，跟在白后缀下面，不要居中漂在整条上。由英文名派生的文字（如 `SURTR ONLY`）在数据层就转大写；只靠 CSS `uppercase` 时，图层文字和测试读到的仍是原样。

用户在检查器里把水平 / 垂直 / 字号调舒服之后，**把数字写回 `defaultX` / `defaultY` / `defaultFontSize`**，不要只留在草稿里。

### 4. 材质用「职责」分，不要处处渐变

参考图里每种底都有分工，照抄分工：

- **场景条**：同一张 AVG，上条裁天空/远景，下条裁地面/近景（改 `object-position`），再盖一层暗纱和细颗粒。
- **纸色条**：平涂纸色 + 轻微斜纹，不要再铺一张风景。
- 左边立绘区可以露场景，但切面以右栏材质为准。
- 画布底和字填充底可以是两张 AVG。字用 `background-clip: text` 按画布对齐透出字背景，比同图同色更分得开。

背景从现有 AVG 库挑一张和参考气质接近的做默认，默认立绘也要符合系列气质。浅底上浅色衣服会溶掉，默认立绘选对比强的。

**能导出的写法。** 下面这些都在实际导出里核过；新组合仍要打开 PNG 看：

- 斜边、三角、尖角用 SVG `polygon`，不用 `clip-path`；方括号这类粗线框用几块实心 DOM 拼，不用 CSS `border`。立体感用错位实心层，不用 `drop-shadow`。
- 字面要纹理又要跟图层颜色走：`background-clip: text` + `-webkit-text-fill-color: transparent`，渐变用 `currentColor`。
- 斑驳、挖缝用 SVG 噪点做 `mask-image`，阈值压到只剩稀疏碎点。`mask-image` 只作用在元素自身的边框盒内，盒外的挤出层、引号会被裁掉：蒙版放在内层 span 上，向外撑开 padding 再用负 margin 收回，引号放到蒙版外。
- 文字用 `scaleX` 压窄时，挂在字尾的引号、角标放进压窄的 span，用 `left: 100%` 跟住，再反向 `scaleX` 回来；放在外层会按未压窄的宽度定位。
- SVG filter id 用 `useId` 生成，避免多个模板同时挂载时串用。

### 5. 装饰能少则少

花边、角花、logo 最容易把相似度做崩。

- 参考没有的，不要补。视频标题里有、封面上没有的（例如肉鸽参考标题带 N15，画面上没有），不要做成主结构；要留就做成小图层或可关。
- 参考有、但你画不像的，用现成素材或直接拿掉。低配最后默认花边是「无」，右上角手绘金角花也删了。
- 不要把「紧急」做成红底色块。参考是红字本身，不是标签按钮。
- 红划痕、涂鸦、抓痕很容易脏。参考有、但画不像，直接拿掉。需要字和底分离时，用「字透出另一张 AVG」比手绘划痕稳。
- 装饰不要放在会被 `clip-path` 切掉的一侧。
- 会和文字相撞的装饰（刻度盘的数字、散落贴纸）要么设避让区，要么写测试检查包围盒不相交。

### 6. 对照、收默认、导缩略图

按 [视觉迭代指南](封面视觉迭代与验收.md) 进行「同尺寸对比 → 说明差距 → 修改 → 重新截图」循环。先修骨架和阅读顺序，再修人物融合、字形、材质和光效。测试通过只证明所测行为，不证明像参考图；还有明显差距就继续迭代，不设「改满三轮即完成」的视觉标准。

1. 每轮 `shot.mjs` 出新截图，`pair` 看整体、`blend` 看偏移，写一句「这轮改什么」再动手。
2. 只改仍不像的那一层：切面、条高、字号、压暗，不要同时重画。
3. **默认值写在哪。** 默认稿的立绘位置读模板元数据（`src/data/templates.ts`）里的 `defaultImageScale / defaultImageX / defaultImageY`，不是种子里的图片图层；图层坐标和字号在 `src/data/seeds/<id>.ts` 和组件默认里。只改一处，测试和缩略图里看不出变化。
4. 用户口头调参（「再大」「往左」「这个不要」）以检查器读数为准，固化进模板。用户丢来 `*_配置.json` 时，按里面的 `draft` / `elements` 写回上面这些默认值、填色和默认背景立绘，并升一次 layout 迁移键、清掉已烘焙进默认的 `elementStyles`；不清的话，旧偏移和新默认会叠两次。
5. 色块（期数竖线、色条）要能改色，必须是独立 `CoverElement`：外层 `color` + `background: currentColor`，`elements.ts` 标 `hasColor`。检查器默认只给 `kind === "text"` 出调色盘，嵌在文字里的 `<span>` 改不了。
6. 精英 0 原画、自带场景的精二常带特效碎片或背景，参考里多半已经擦掉。在参考图上（画布坐标）手描轮廓，按配准换回原图像素，放进 `src/lib/artCutouts.ts`；只描画布里露出来的那一截，要留的场景用 `fill-rule: evenodd` 挖洞。描完叠回参考检查一遍。
7. 构图、默认色、主标题字体定了之后，`node scripts/qa/editor-export.mjs <id>` 查整页编辑器和真实 PNG，`npm run thumb -- <id>` 写两份缩略图。新模板还要在 `src/lib/thumbs.ts` import `<id>-shot.webp`；只改 `public/thumbs/` 会被缓存，首页还是旧图。
8. 在编辑器里改标题、换立绘、换背景再导出一次。旧草稿若被覆盖值卡住，提示重置。

图层命名用职责（`operation`、`guide`、`slogan`），不要用参考 UP 的品牌当 id。

## 质量对照清单

并排主参考，逐条打勾。有一条不像就还没做完。

- [ ] 分栏和切面的倾斜、起点、终点接近，不是竖直硬切；自由构图的卡片角度、尖角位置在 50% 叠图里对得上。
- [ ] 立绘和栏的前后关系正确（谁遮谁）；立绘不挡任何正文。
- [ ] 横条数量、相对高度、中条材质（纸 / 色块 / 图）一致。
- [ ] 主标题字体、描边重量、金/白（或宋体栏目名 / 黑体冲字）分工接近；字墨宽高按实测反推过。
- [ ] 副信息（英文小标、卖点句、署名色）在同一锚点，没有改成居中海报。
- [ ] 没有多出来的线、光晕、角花、logo、红框、视频标题里才有的关卡码。
- [ ] 换一个更长/更短的标题仍能站住，不会撑破或空一大块。
- [ ] 字体与图片解码后，整页编辑器和默认稿都已截图检查。
- [ ] `editor-export.mjs` 拿到真实 PNG 并打开看过；描边、渐变、遮罩和 SVG 纹理没有丢失。
- [ ] 首页缩略图是新构图，不是旧稿。

## 各模板里只属于它的判断

通用做法已经并进上面的流程，这里只留每套模板特有的取舍。具体数值在各参考目录的 `INDEX.md`。

### 低配攻略

主参考 `references/zc-event/03_BV1yz4y1X7fX.jpg`。

- 三横条里，中条是「纸」，上下是「同一张夜景的不同裁切」，比三条都铺图更像。
- 宋体金字 + 含「的」拆分，比全用黑体或全金更像活动关封面。

### 模组测评

主参考 `references/keluojia-42/main_16x9.png`（教学视频成品帧），做法拆解见 [模组测评四列封面做法](模组测评四列封面做法.md)。

- 不变量：四等分无缝竖栏、每栏「渐变映射的精二 → 窄体 UNIT → 清楚的精一」、底部暗带加黄渐变、白字黄期号的大标题横跨四栏。
- 渐变映射用一个 SVG `feColorMatrix`（先取明度，再乘代表色）；精二映射前加对比（明度 ×1.3 − 0.18），否则整栏发灰。
- 每栏 `overflow: hidden` 但不设 `z-index`，标题才能压过所有立绘。立绘槽比栏宽（1080 见方居中），栏负责裁两侧。

- `OperatorLayer` 根节点总带 `relative`，外面写 `absolute inset-0` 会被盖掉、高度变 0；要铺满就套一层定位容器。
- Morganite 不能分发，用 OFL 的 Six Caps 代替，同色 `-webkit-text-stroke` 加粗到参考的竖条宽度。
- 标题用 MiSans Black（900）；期号字号是中文的 1.15 倍，数字高度约为中文字身的 87%。标题那一截压到接近黑（参考亮度约 25～55），黄渐变只在最底边约三成。
- 标题的「距离 0、大小 25」投影用双层 DOM（模糊黑字垫底），动感模糊用 `feGaussianBlur` 只在横向给大 `stdDeviation`。
- 「废土搭配」调色只叠在精一上；精二、代表色和 UNIT 是照着调完色的成图取的，再调一遍就重复了。

## 明确不要做的

- 不要先做一套「更现代、更干净」的改版再往回凑。先像，再谈简化。
- 不要用官方危机合约标、活动 logo 冒充实心字。
- 不要把参考图当 `background-image`。
- 不要搬参考 UP 的 logo、花体签名、STAFF 装饰条。复刻的是分栏和字级，不是别人的品牌壳。
- 不要两段大标题用同一字体、同一倾斜、再靠两个近色区分。
- 不要在没看第二张同系列参考之前，把某一张的特例写成死结构；只有一张时，也不要用「这一品类常见」去加参考上没有的件。用户给了两条链接时，不要把差构图那张当骨架。
- 不要为截图或拼图另装 sharp、PIL 或用系统 Edge；用 `scripts/qa/` 里的 Chromium 脚本。
- 不要整屏蒙黑。
- 不要给主题擅自加红划痕、涂鸦、抓痕。参考明确依赖不规则光痕时，按它的方向、疏密和亮度复现，并检查实际导出；不要用等距长直线充数。

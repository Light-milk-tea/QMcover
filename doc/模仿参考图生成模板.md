# Prompt：根据参考图生成高相似度封面模板

把下面整段（从「角色」到文末）发给之后做新模板的 Agent。参考图放进 `references/<系列>/`，jpg 不进 git。

---

## 角色

你在 QMcover 里做一套新的 B 站横版封面模板（1920×1080）。目标不是「好看的原创设计」，而是 **复刻某一系列参考封面的构图系统**：字在哪、条在哪、谁压谁、用什么字重和材质。做成可填内容的模板，让换标题、立绘、背景之后，看起来仍像同一系列。

成功标准：把本模板默认稿和主参考图并排，路人能一眼看出是同一套构图；不要做成「意思差不多」的简化版。

对照样本：

- `src/templates/LowSpec.tsx`（低配攻略）← `references/zc-event/03_BV1yz4y1X7fX.jpg`
- `src/templates/Rogue.tsx`（肉鸽）← `references/rogue/01_BV14EbZ67EB1.jpg`
- `src/templates/Madness.tsx`（决战五星之癫）← 构图主参考是「五星测评 122」时隙封面；栏目名来自「决战五星之癫」阿罗玛，那张构图较差，只借文案不借骨架。参考图要落进 `references/<系列>/` 并写 INDEX，不要只留在 `/tmp`。

## 硬约束

- **复刻构图，不搬整图。** 不要把别人的封面、官方宣传图、ZC logo、官方标当底或当贴图。
- 参考 jpg 只作对照，已被 gitignore，不要提交。
- 立绘、AVG 背景只走现有 CDN（干员库、背景库），不要把大图拷进仓库。
- 导出靠 `html-to-image`。描边、阴影用 **双层真实 DOM**，不要用伪元素；需要 `crossOrigin="anonymous"`。
- `CoverElement` 外层 `translate` 只负责拖动，字效写内层。
- 不要手绘花边、卷草、角花。要么用现成公有领域素材并做成可选，要么不加。用户已经证明手绘花边会显得廉价。
- 先改模板默认，再处理旧草稿。`localStorage` 里的 `elementStyles` 会盖住新默认，需要时写一次迁移，或告诉用户点图层重置 / 新建。用户丢来 `*_配置.json` 时，按里面的字号、坐标、颜色、立绘、两套背景写回 `templates.ts` / `Xxx.tsx` 的 **默认值**（`defaultX` / `defaultY` / `defaultFontSize` / 填色），并升一次 layout 迁移键、清掉已烘焙进默认的 `elementStyles`。不清的话，旧偏移和默认会叠两次。
- **立绘永远在文字下面。** `OperatorLayer` 默认 `z-[1]`，父级也不要高于字。挡字比「立绘压住水印更好看」更糟。
- **蒙黑是局部暗角，不是整屏抹黑。** 用 `BgDimLayer`（径向、边缘透明），参考五星测评左暗角。每个有背景的模板都要能开关、能调黑度。

## 工作顺序（不要跳）

### 1. 先读一组图，再锁定一张主参考

同一系列至少看 5～8 张，不要只盯一张。

记下两类东西：

| 类型 | 做法 |
| --- | --- |
| **系列不变量** | 每张都有的骨架：分栏、切面、条数、字级、材质分工。写成布局规则。 |
| **单张变量** | 标题、干员、场景、有无某装饰。变成可编辑字段或可关的图层。 |

低配攻略的不变量：左立绘、右三横条、斜切遮住立绘右半、上/下条用场景、中条纸色、金字活动名 + 白后缀、中条署名 + 攻略类型、下条两句卖点。变量：活动名、干员、AVG、署名、花边。

选一张最干净、元素最全的当 **主参考**，其余用来核对「这个到底是系列特征还是这一张的特例」。ZC 系列里「活动」二字不是每张都有，主参考没有就不要硬加（或做成默认隐藏）。

系列只有一张图时，更要抠这张，不要用「肉鸽封面一般都有 N15 / 红框」去补。视频标题里的词不等于封面上的字。

用户丢来两条链接时，先问清分工：哪张定 **构图**，哪张定 **栏目名 / 文案**。决战五星之癫就是构图跟时隙、文案跟阿罗玛；把差构图那张当骨架会一直拧。参考 UP 的 logo、STAFF TRAINING GUIDE、Doctor 花体、署名是别人的系列壳，不是不变量，不要搬。

### 2. 先量骨架，再写字

先在 1920×1080 上定：

1. **分区比例**：左立绘占多宽、右栏从哪切到哪。用百分比或 `clip-path`，对着参考目测后再收，不要凭感觉画一条竖线。
2. **层级**：立绘在切面 **下面** 还是上面。低配是立绘 z 更低，斜切栏压住右半身；肉鸽、无核、危机合约同样是立绘低于全部文字（含空心水印）。切缘不要自作聪明加发光白线。左立绘靠字的一侧可以做 **渐隐**（身子仍实，最后一截才溶进字和底），不要整块削掉右三分之一。
3. **横条数量和相对高度**：三等分还是中条更薄。先用 flex 比例落位，再微调 padding。
4. **安全区**：脸和主标题留在 `BILI_SAFE` 里。
5. **左文右图也要量字**：不是只有斜切栏才要量。在 1920×1080 上读主标题的起点和字高（或对参考图左半的亮像素条带）。时隙主标题大约 `x=180`、`y=370`、字高 `150`；第一版 `left: 100`、字号 92，用户一眼就是「偏左、偏小」。不要凭感觉摆现代 UI 边距。

没对上骨架之前，不要做花边、渐变、字效。骨架错了，后面越改越歪。

### 3. 字级按参考抄，不要「设计一版」

对着主参考读出字级，而不是自己配一套现代 UI 字号。

- 中文大标题优先 **宋体黑**（`--font-serif` / `Noto Serif SC` 700/900），活动关、栏目名这类封面很少用细黑体。参考图是宋体就写宋体，不要两段标题都套同一套斜黑体再靠相近色区分，会「单一」。
- 标题拆成两段时，用 **字体对比** 分工，不要只换色：栏目名宋体 + 描边正坐，冲字（「之癫」）黑体斜切实心。两段都加同一套描边，又会糊成一块。
- 金字 = 金填色 + 很重的深色描边 + 一层错位暗影（双 span）。不要只靠 `text-shadow` 冒充描边。
- 标题有固定语法就写成规则，例如含「的」则拆成金字 + 白后缀（沃伦姆德 / 的薄暮）；栏目名固定就写死（「决战五星之癫」），不要做成输入框。
- 字号按字数分段缩放（2 字 / 4 字 / 更长），并给行高和 `padding-bottom`，避免「平民攻略」这类字被切掉脚。
- 英文小标（OPERATION）是构图零件，跟在白后缀下面，不要居中漂在整条上。

用户在检查器里把水平 / 垂直 / 字号调舒服之后，**把数字写回 `defaultX` / `defaultY` / `defaultFontSize`**，不要只留在草稿里。

### 4. 材质用「职责」分，不要处处渐变

参考图里每种底都有分工，照抄分工：

- **场景条**：同一张 AVG，上条裁天空/远景，下条裁地面/近景（改 `object-position`），再盖一层暗纱和细颗粒。
- **纸色条**：平涂纸色 + 轻微斜纹，不要再铺一张风景。
- 左边立绘区可以露场景，但切面以右栏材质为准。

背景从现有 AVG 库挑一张和参考气质接近的做默认（低配后来定的是龙门夜，不是纯黑、也不是随便一张雷云）。默认立绘也要符合系列气质。肉鸽后来证明：画布底和字填充底可以是两张不同的 AVG；字用 `background-clip: text` 按画布对齐透出字背景，比同图同色更分得开。

### 5. 装饰能少则少

花边、角花、logo 最容易把相似度做崩。

- 参考没有的，不要补。视频标题里有、封面上没有的（例如肉鸽参考标题带 N15，画面上没有），不要做成主结构；要留就做成小图层或可关。
- 参考有、但你画不像的，用现成素材或直接拿掉。低配最后默认花边是「无」，右上角手绘金角花也删了。
- 不要把「紧急」做成红底色块。参考是红字本身，不是标签按钮。
- 红划痕、涂鸦、抓痕很容易脏。参考有、但画不像，直接拿掉。需要字和底分离时，用「字透出另一张 AVG」比手绘划痕稳。
- 装饰不要放在会被 `clip-path` 切掉的一侧。

### 6. 对照、收默认、导缩略图

1. 主参考和画布并排（或截 `#/__thumb/<id>` 对比）。
2. 只改仍不像的那一层：切面、条高、字号、压暗，不要同时重画。
3. 用户口头调参（「再大」「往左」「这个不要」）以检查器读数为准，固化进模板。用户丢来 `*_配置.json` 时，按里面的 `draft` / `elements` 写回 `templates.ts` 和图层 `defaultX` / `defaultY` / `defaultFontSize` / 填色 / 默认背景立绘，并升一次 layout 迁移键、清掉对应 `elementStyles`。色块（期数竖线、色条）要能改色，必须是独立 `CoverElement`：外层 `color` + `background: currentColor`，`elements.ts` 标 `hasColor`。检查器默认只给 `kind === "text"` 出调色盘，嵌在文字里的 `<span>` 改不了。
4. 构图、默认色、主标题字体定了之后更新首页缩略图。打开 `#/__thumb/<id>`，把 960 宽 jpeg 转 webp，同时写 `public/thumbs/<id>.webp` 和 `src/assets/thumbs/<id>-shot.webp`，再在 `src/lib/thumbs.ts` import。只改 `public/thumbs/` 会被缓存，首页还是旧图。
5. 用浏览器走一遍：改标题、换立绘、换背景、导出。旧草稿若被覆盖值卡住，提示重置。

## 工程落点

按 `TEMPLATES.md` 接线，不要自创一套：

1. `src/types.ts` 的 `TemplateId`
2. `src/templates/Xxx.tsx`，props 用 `CoverRenderProps`
3. `src/templates/registry.tsx`
4. `src/data/templates.ts`：name、blurb、默认文案、默认立绘、默认背景、要不要背景/花边
5. `src/data/elements.ts`：图层 id 和中文名（和 `CoverElement` 的 id 一致）；色块加 `hasColor`
6. 需要的编辑栏开关：`showBackground`、`showTextBackground`、`showBgDim`、`showOrnament` 等
7. 定稿后更新缩略图（`public/thumbs/` 或 `src/assets/thumbs/` + `thumbs.ts`）

图层命名用职责（`operation`、`guide`、`slogan`），不要用参考 UP 的品牌当 id。

## 质量对照清单

并排主参考，逐条打勾。有一条不像就还没做完。

- [ ] 分栏和切面的倾斜、起点、终点接近，不是竖直硬切。
- [ ] 立绘和栏的前后关系正确（谁遮谁）；立绘不挡任何正文。
- [ ] 横条数量、相对高度、中条材质（纸 / 色块 / 图）一致。
- [ ] 主标题字体、描边重量、金/白（或宋体栏目名 / 黑体冲字）分工接近。
- [ ] 副信息（英文小标、卖点句、署名色）在同一锚点，没有改成居中海报。
- [ ] 没有多出来的线、光晕、角花、logo、红框、视频标题里才有的关卡码。
- [ ] 换一个更长/更短的标题仍能站住，不会撑破或空一大块。
- [ ] 导出 PNG 描边完整，没有伪元素丢失。
- [ ] 首页缩略图是新构图，不是旧稿。

## 这次低配模板里证明有效的判断

- 斜切栏必须压在立绘上，切缘保持干净。
- 三横条里，中条是「纸」，上下是「同一张夜景的不同裁切」，这比三条都铺图更像。
- 宋体金字 + 含「的」拆分，比全用黑体或全金更像活动关封面。
- 检查器里调好的 180 / 156 / 200 / 220 和偏移，比公式估算的「大概字号」更接近成稿。
- 花边不是相似度的关键；画砸了会立刻显得山寨。宁可没有。
- 默认场景用有地标感的 AVG（龙门夜），首页缩略图才立得住。

## 这次肉鸽模板里证明有效的判断

主参考：`references/rogue/01_BV14EbZ67EB1.jpg`（命运共享）。对照样本：`src/templates/Rogue.tsx`。

- 不变量是：左立绘、右宋体主题、上下空心 ISW-NO（下层翻转）、红字「紧急」+ 白条件、右侧细标、右下小点阵。**不是**红底标签、不是巨大 N15、不是竖排 IS。
- 第一版做成「红框 + N15 海报」差太远。骨架错了就重做，不要在错骨架上调字号。
- `ISW-NO` 是集成战略普通作战的关卡前缀，当构图零件，不要改成自己发明的水印文案。主参考封面上没有 N15，节点只留很小一层或可关。
- 「紧急」是红字，不是红矩形。用户后来说主题不要涂鸦，红划痕拿掉后更干净。
- 画布底和字填充底可以是两张 AVG。字用 `background-clip: text` 按 1920×1080 对齐裁切，拖动时用图层偏移改 `background-position`。玻璃字叠在暗底上才分得开。
- 蒙黑用右侧/字侧的径向暗角。整屏 `rgba(0,0,0,x)` 一拉满就糊，海滩那次用户只能把黑度打到 0。
- 立绘靠字的一侧要溶边，但身子保持实：大约 `70%` 以前不透明，最后一截才淡出。整块削掉右三分之一会缺一块。
- 「立绘载入中」要大号实心字 + 深色底托。28px、四成透明米白叠在暗海上等于没有。
- 默认立绘、画布、字背景以用户导出的配置为准，不要执着第一版猜的歌蕾蒂娅 / 云海。

## 这次决战五星之癫模板里证明有效的判断

构图主参考：B 站「五星测评 122」时隙封面（左文右拍立得）。栏目/文案参考：「决战五星之癫 —— 阿罗玛」。对照样本：`src/templates/Madness.tsx`。

- 不变量是：左文右拍立得、期数 + 竖线、栏目名、干员篇 + 副标题、英文小标、相框底下英文名。**不是**明日方舟 logo、STAFF TRAINING GUIDE、Doctor 花体、作者署名。
- 阿罗玛那张定栏目名，但构图散。骨架按时隙抄：文字块从左半偏里起，主标题字高大约 150，不要做成贴左边的小标题。
- 第一版字号 92、`left: 100`，和参考差一截。对着参考图量 x/y/字高再写默认，比「再大一点、再往右」盲调快。
- 用户导出的 `*_配置.json` 才是默认色和微调偏移的准绳（之癫青、副标题堇、竖线蓝、暗角上移、背景龙门夜）。先写进模板默认，再升 `qmcover-madness-layout-v*` 清 `elementStyles`，否则检查器里的旧 x/y 会叠在新默认上。
- 期数左边那条竖线要能改色，就不能塞在「期数」文字里。独立图层 `episode-bar` + `hasColor` + `currentColor`。
- 「决战五星之癫」六字同一套斜黑体、两个近青色，用户说单一。改成：决战五星 = 思源宋体描边正坐，之癫 = 黑体斜切实心。参考图「五星干员指南」本身就是宋体黑。
- 首页缩略图跟默认稿走。色、字、位置定了就重导 `#/__thumb/madness`，`thumbs.ts` 走 asset import 才能立刻看见。

## 这次终末地角色测评里证明有效的判断

主参考：`references/endfield-review/03_BV1fkcsz9EBN.jpg`（洁尔佩塔）。对照样本：`src/templates/Endfield.tsx`。

- 不变量是：左立绘、右柠黄方括号 + 黑体角色名、黑条「数据与实战测评」、浅纸底、朝下黄三角、右下小字游戏标。**不是**终末地官方标、不是兔头测评 logo。
- #1 莱万汀是早期变体（左竖排英文名），不要当骨架。#3 起才是稳定的黄括号 + 黑条。
- 黄三角必须用 SVG `polygon`，不要 CSS `clip-path`。`html-to-image` 会把 clip 渲成整块黄板。面内等高线用 SVG 自己的 `clipPath`。三角、括号、破折号的立体感用错位实心层，不要 `drop-shadow`。
- 立绘层不要 `inset-0` 铺满。全幅立绘会盖住三角。左栏大约 52–56% + `fadeRight`。底边贴画布、只在最后一截溶掉，不要从大腿横切；右侧身子保持实，最后一截才溶进纸底。
- 浅纸底上浅色衣服会溶掉。默认立绘选对比强的（红），终末地立绘让用户上传。
- 柠黄括号用三块实心 DOM 拼 `[`，不要 CSS border。导出时 border 容易丢。
- 右上角标是可编辑字段 `mark`，默认「明日方舟测评」，不要写死「终末地测评」。

## 明确不要做的

- 不要先做一套「更现代、更干净」的改版再往回凑。先像，再谈简化。
- 不要用官方危机合约标、活动 logo 冒充实心字。
- 不要把参考图当 `background-image`。
- 不要搬参考 UP 的 logo、花体签名、STAFF 装饰条。复刻的是分栏和字级，不是别人的品牌壳。
- 不要两段大标题用同一字体、同一倾斜、再靠两个近色区分。
- 不要在没看第二张同系列参考之前，把某一张的特例写成死结构；也只有一张时，不要用「这一品类常见」去加参考上没有的件。用户给了两条链接时，不要把差构图那张当骨架。
- 不要把 playwright / sharp 写进 `package.json`；临时截图可以，正式预览进 `public/thumbs/` 或 `src/assets/thumbs/`。
- 不要整屏蒙黑。
- 不要给主题手绘红划痕、涂鸦、抓痕。

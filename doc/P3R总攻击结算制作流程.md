# P3R 总攻击结算图：制作流程

整理自 B 站教程 [如何学习 P3R 的设计风格并制作一张同人设计图](https://www.bilibili.com/video/BV1TCqrBREsh/)（BV1TCqrBREsh，约 9 分 40 秒）。视频用 Photoshop 从新建画布一路做到导出，下面按它的顺序记下步骤和数值，最后写 QMcover 的「总攻击」模板怎么对应。参考帧和原视频在 `references/p3r-allout/`，不进 git，索引见 [INDEX.md](../references/p3r-allout/INDEX.md)。

## 一句话

平涂底色上压两道 30% 黑的同心圆环；人物在环里的部分换成用背景色滤色过的版本；背景大字斜切，环里实心、环外描边；台词用粗无衬线白字摆在环里。

## 拆成五层

教程先拆解游戏原图，再说可以分成五层：

| 层 | 内容 | 要点 |
| --- | --- | --- |
| 背景 | 纯色填充 | 选人物的代表色或应援色。 |
| 背景文字 | 两个英文词，斜切 | 环里实心深色，环外只留描边。 |
| 人物 | 抠好的立绘 | 带一层比底色深的斜向投影。 |
| 聚焦圆环 | 两道同心环 | 环盖住的地方，底色变暗，人物变色。 |
| 台词 | 白色短句 | 放在环的区域里，行距、字距都收紧。 |

教程最后归纳的核心是三件事：**聚焦圆环、背景的实心/空心文字、图像调色**。别的都可以换。

## 字体

| 用途 | 教程用的 | 说明 |
| --- | --- | --- |
| 台词 | Outfit Black | 几何无衬线最粗一档。可以混字重，比如细的 PLEASE 配粗的 TRUST ME. |
| 背景文字 | Triumvirate CG Inserat Regular | 很窄的粗黑体。 |

两款都不是游戏原字体，只是风格接近。

## Photoshop 步骤

### 1. 画布和底色

1. 新建 1920×1080，先存到一个固定文件夹，后面随时 Ctrl+S。
2. 图层面板底部「创建新的填充或调整图层」→ 纯色。双击缩略图就能换色。
3. 颜色用人物代表色，不确定就查 wiki 或萌娘百科里的应援色。

### 2. 双层聚焦圆环（全矢量）

1. 椭圆工具按住 Shift 拉一个**非常大的正圆**，大到只有画布角落没被盖住。
2. Ctrl+J 复制一层，Ctrl+T 用顶栏数值从中心缩小。两圆同心，留出一圈宽度。
3. 两层一起选中，Ctrl+E 合并成一个形状图层。两条路径仍然都在。
4. 用路径选择工具框选两条路径，在顶栏布尔运算里选一种，把中间切掉，得到一个圆环。
5. Ctrl+J 复制这个环，Ctrl+T 从中心放大，两环之间**留一点空隙**。这道缝会在暗区里露出一条底色细线。
6. 两个环都填纯黑，Ctrl+G 编组，**组不透明度 30%**。

结果是：环外（包括圆心那块洞）是原底色，两道环把底色压暗三成，中间夹一条亮缝。

### 3. 人物和环内调色

1. 放入抠好的立绘（原图像）。
2. Ctrl+J 复制一层，叫「调色图像」。图层样式 → 颜色叠加：**颜色同背景，混合模式滤色，不透明度 75%**。教程说滤色最接近原作，也可以试别的模式。
3. 按住 Ctrl+Shift 点两个圆环的缩略图，得到两环的选区。
4. 选中调色图像，点「添加图层蒙版」，选区自动变成蒙版。于是只有落在环里的人物部分被调色。
5. 要挪人物时，先点图像和蒙版中间的链接解绑，再同时选中调色图像和原图像一起移动。

### 4. 背景文字

1. 打两个词，分成两个图层，方便各自调整，再放进同一组。
2. Ctrl+T → 右键「斜切」，直接输数值。可以试 **H −11、V −18**，速度感很强。H 是左右，V 是上下。原作也有只旋转、不斜切的。
3. 调大小和位置，让字从人物后面斜着穿过去。
4. 按住 Alt，把前面的圆环蒙版拖到文字组上。文字只在环里显示，再把字改成深色。
5. 描边字：按住 Alt 把组里的文字拖出组外复制一份，填充改 0，图层样式加描边。描边颜色比实心字**亮一些**。描边层要放在实心字**下面**，否则会串层。

### 5. 投影

1. 原图像加投影，颜色同实心文字，角度和前面一致。
2. 调色图像放进一个单独的组，把蒙版从图层移到组上，再给调色图像加投影，**颜色同背景**。这样投影在环里是底色、环外是深色，人物轮廓被圆环切成两段，这就是「分割效果」。
3. 圆环组必须在调色图像**下面**。放到上面的话，投影会被压暗，分割效果出不来。

### 6. 台词

1. Outfit Black，白色。
2. **一定要落在圆环的区域里**，超出环就不好看。
3. 字间距可以收小，字重也可以分粗细，例如细的连接词夹在粗的主词中间。

## 图层顺序（上到下）

| 顺序 | 图层 | 关键设置 |
| --- | --- | --- |
| 1 | 台词 | Outfit Black，白色 |
| 2 | 调色图像组 | 组上挂圆环蒙版；图层颜色叠加（背景色，滤色，75%）；投影颜色同背景 |
| 3 | 圆环组 | 两个同心黑环，组不透明度 30% |
| 4 | 原图像 | 投影颜色同实心文字 |
| 5 | 实心背景文字组 | 挂圆环蒙版，深色 |
| 6 | 描边背景文字 | 填充 0，描边比实心亮 |
| 7 | 纯色填充 | 人物代表色 |

## 从参考图量到的数

把参考帧缩到 960×540，按颜色分出底色、暗环和亮缝，再拟合圆。坐标都换算到 1920×1080。

- **青色主参考**：圆心约 `(1270, −170)`，在画布右上方外面。圆洞半径约 955，亮缝半径约 1437。人脸落在圆洞里，台词和左下的背景字落在暗环里，左下最角上又露出一点底色。
- **粉色（教程作者的成品）**：底色 `(240,120,144)`，暗环 `(168,84,96)`，正好是底色的七成，说明就是 30% 黑。投影大约是 35% 黑往右下偏。
- **灰色游戏原作**：浅灰圆洞套着人物头和手臂，左上是暗区，暗区里有一条亮缝。明暗差比 30% 大，是原作自己的配色。

三张图的共同点：圆洞框住人物脸部，台词在暗环里，暗环里有一道细亮缝。

## QMcover 里怎么实现

实现在 `src/templates/AllOut.tsx`，几何和配色在 `src/lib/allOutLayout.ts`、`src/lib/allOutPalette.ts`。

| PS 做法 | DOM 做法 |
| --- | --- |
| 纯色填充 | 画布底色 = 主题色 |
| 两个黑环，组 30% | SVG 两个描边圆，黑色 30% |
| 圆环蒙版 | 同一份几何生成 SVG data URL，写进 `mask-image`，贴在整张画布大小的包裹层上 |
| 颜色叠加：背景色、滤色、75% | SVG `feColorMatrix`。滤色对固定颜色是逐通道的线性变换，`out = in × (1 − a·c) + a·c`，透明区不受影响。模板用 a = 0.6：青色这种很亮的底色按 75% 会把深色衣服洗成一片白 |
| 调色图像的投影（背景色） | 调色那份立绘再加 `drop-shadow`，颜色同底色，然后整体被圆环蒙版裁切 |
| 原图像投影 | 原立绘 `drop-shadow`，35% 黑，往右下 |
| 实心字 + 描边字 | 描边层用 `-webkit-text-stroke`，不挂蒙版；实心层挂圆环蒙版，盖在描边上 |
| 斜切 H −11 / V −18 | `transform: skew(-11deg, -18deg)` |
| Outfit Black / Inserat | 台词 `Outfit Variable` 900，字距 −0.045em，行距 0.74em，行尾句点挂在右缘外；背景字 `Anton`（免费的 Inserat 类窄粗黑），关掉合成粗体。中文都落到 `Noto Sans SC` 900 |

编辑栏里的台词、背景大字和角落署名都是多行框，回车就换行，画布按输入的行排；不换行时，台词按词自动排，背景大字对半拆成两行。

选中「聚焦圆环」后，检查器里可以调水平、垂直、旋转，以及「圆环大小」（圆洞半径）和「圆环粗细」（内环宽度）。亮缝宽度固定，外环按原比例跟着内环变粗变细。蒙版用同一份几何重新计算，所以环里的实心字和调色人物会跟着一起变。

导出走 `html-to-image`：mask 用 SVG data URL，调色用页面内的 SVG filter，描边用真实 DOM 文字，没有伪元素。

## 变体

- 台词和人物左右对调（紫色那张：人物在左，台词在右）。
- 圆环挪位置，让圆洞框住不同的身体部位。
- 实心和空心在左右两边互换，只要环里实心、环外空心这条规则不变。
